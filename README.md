# opencart-steps

Cucumber step definitions for OpenCart, the open-source shop (the storefront: categories, search, a product with
options, the cart, coupons and the checkout; the customer's account; the administration: the catalog, orders, customers
and coupons), with [webship-js](https://webship.co/docs/webship-js/2.0.x), a BDD browser automation harness built on
Playwright and Cucumber-js.

The steps, their features, the test site and CI come with the first release, `2.0.0`.
